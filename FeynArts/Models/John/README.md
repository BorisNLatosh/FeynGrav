# GR with a massive scalar and John interaction

The base action contains GR and the canonical scalar terms $\tfrac12 g^{\mu\nu}\partial_\mu\phi\partial_\nu\phi-\tfrac12m^2\phi^2$, plus
$$\int d^4x\sqrt{-g}\,\beta G^{\mu\nu}\partial_\mu\phi\partial_\nu\phi.$$
The scalar has arbitrary mass ``FeynGrav`ScalarMass``; the independent coupling is ``FeynGrav`JohnBeta``. There is no extra half in the John term and no scalar self-potential. Expansion is about flat space and phi = 0. GaugeFixingEpsilon = 2 and the negative gravitational ghost propagator are inherited. Symbolic D is a dimensional-regularisation continuation of the four-dimensional action.

## Inventory

TTT, TTTT and TUU are unchanged. TSS and TTSS combine the minimal massive-scalar contribution with the John interaction through kappa squared. No duplicate coupling row and no free-propagator correction is introduced. John is constructed using G5 = -beta phi and the covariant contracted Bianchi identity, up to a boundary term.

## Use

For a complete scalar `2 -> 2` example, see [example 10](../../../Examples/10.%20Scalar_Scattering_John_Tree_Level_FeynArts.nb). It displays all three graviton-exchange diagrams and calculates the on-shell amplitude directly, separating the terms of orders β⁰, β¹ and β².

Follow the [Single-Scalar-Tensor-Minimal-Coupling loading and native calculation example](../Single-Scalar-Tensor-Minimal-Coupling/README.md), replacing both model names by `John`. Use a fresh kernel. The supplied files need no builder, source-library import or FORM execution at model load. Alternatively load FeynGrav after requesting FeynArts to register the folder automatically.

For example, after loading FeynCalc-patched FeynArts and registering the folder:
```wl
FeynArts`InitializeModel["John", FeynArts`GenericModel -> "John"];
top = FeynArts`CreateTopologies[0, 2 -> 2, FeynArts`Adjacencies -> {3,4}];
ins = FeynArts`InsertFields[top,
 {FeynArts`S[1],FeynArts`S[1]} -> {FeynArts`T[1],FeynArts`T[1]},
 FeynArts`Model -> "John", FeynArts`GenericModel -> "John",
 FeynArts`InsertionLevel -> {FeynArts`Classes}];
raw = FeynArts`CreateFeynAmp[ins, FeynArts`PreFactor -> 1,
 FeynArts`GaugeRules -> {}, FeynArts`MomentumConservation -> True,
 FeynArts`Truncated -> True];
diagrams = FeynCalc`FCFAConvert[raw,
 FeynCalc`IncomingMomenta -> {p1,p2}, FeynCalc`OutgoingMomenta -> {q1,q2},
 FeynCalc`LorentzIndexNames -> {mu,nu,rho,sigma,a,b,c,d},
 FeynCalc`ChangeDimension -> D, FeynCalc`Contract -> False,
 List -> True, FeynCalc`Prefactor -> 1];
```

Specialise mass and beta by replacement in converted expressions; beta = 0 recovers the minimal massive scalar sector (the unified scalar model with both potential couplings set to zero). The vertex cutoff does not discard products quadratic in beta or higher total powers of kappa. There are three graviton channels in scalar elastic scattering and four channels (contact, graviton exchange, two scalar exchanges) in scalar–scalar to graviton–graviton scattering.

## Adding higher orders in κ

The supplied model contains all its specified interactions through **κ² per vertex**. To extend the cutoff to `N`, retain every lower order and include:

| Sector | Vertices, for `1 <= n <= N` | Coupling order | Source library |
| --- | --- | --- | --- |
| Pure gravity | `h^(n+2)` | κⁿ | `GravitonVertex_n` |
| Minimal scalar kinetic and mass terms | `h^n phi^2` | κⁿ | `GravitonScalarVertex_n` |
| John interaction | Contribution to the same `h^n phi^2` row | βκⁿ | `HorndeskiG5_1_0_n` |
| Gravitational ghosts | Existing `h antighost ghost` only | κ | Existing fixed-gauge ghost rule |

For example, order three adds the five-graviton vertex and `TTTSS`, with both minimal and John contributions in the latter. Pure-gravity order `n` counts `n + 2` graviton legs; scalar and G5 order `n` counts `n` graviton legs. No scalar self-potential or separate two-leg mass insertion is introduced. Preserve the existing propagators, including the negative ghost propagator; the current linear gauge fixing needs no additional multi-graviton ghost contacts.

Each John vertex is linear in β. Products of vertices can contain β² and higher total powers of κ: a vertex cutoff is not a diagram-order cutoff.

The scalar command also generates a potential tensor, which this John model does not use. **Use the specific G5 command:** the current `GenerateHorndeskiG5` batch selects at least three scalar legs and therefore omits the two-scalar John family `a = 1, b = 0`. Generating a file is not evidence of its normalisation. Inspect failures and verify new expressions before installing accepted files in `Libs`; preserve existing sources and provenance.

$$\sqrt{-g}\,\beta G^{\mu\nu}\partial_\mu\phi\,\partial_\nu\phi,
\qquad g_{\mu\nu}=\eta_{\mu\nu}+\kappa h_{\mu\nu}.$$

Include the determinant, inverse metrics that raise the Einstein-tensor indices, and functional-differentiation multiplicities. Compare full tensors with symbolic D and generic off-shell momenta, imposing only total momentum conservation. Check permutations of gravitons and the two identical scalars.
