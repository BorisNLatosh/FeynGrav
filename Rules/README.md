# Interaction rules

These packages construct rules for the library generator and provide
Nieuwenhuizen helpers. Ordinary calculations normally use the library-backed
[main-package commands](../Documentation/Reference.md).

- [Contracts and failure handling](Contracts.md): families, signatures,
  validation, algebra backends and current limitations.
- [Library generator](../Libs/Generator.md): generation and publication workflow.

Use a separate fresh kernel for rule construction and check `FailureQ` before
combining results. Higher-order EsGB and the axion action convention retain the
limitations documented in the contracts guide.
