# CalcFormConverter

Translate supported exact FeynCalc expressions to FORM, run FORM/TFORM and
reconstruct results. The converter loads with FeynGrav and can also be loaded
independently. Loading it does not install software or execute FORM.

- [User guide](UserGuide.md): workflows, commands, options, vocabulary,
  conventions, failures and performance limits.
- [Developer guide](DEVELOPER.md): implementation and regression tests.
- [Mapping format](FORMAT.md): saved-file contracts and compatibility.
