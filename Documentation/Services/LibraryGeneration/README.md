# Library generation

[Documentation index](../../README.md) · [Complete symbol index](../../Symbols.md)

Load `Libs/Generator.wl` in a separate fresh kernel. Generate commands construct rules, run the converter and write extensionless libraries; use an explicit fresh existing `OutputDirectory` when testing. Bare-symbol `Check*` commands inventory filenames only. No generation or software installation occurs merely from loading definitions. See the [complete guide](./Guide.md).
