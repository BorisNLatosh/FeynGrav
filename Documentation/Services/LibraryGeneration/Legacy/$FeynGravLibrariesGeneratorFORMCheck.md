# $FeynGravLibrariesGeneratorFORMCheck

[Group overview](./README.md) · [Documentation index](../../../README.md)

**Symbol:** ``FeynGravLibrariesGenerator`$FeynGravLibrariesGeneratorFORMCheck``. **Baseline:** 4.2.0.

Deprecated startup-check setting. Its value is ignored: loading the generator neither checks nor launches FORM.

Use [FeynGravLibrariesGeneratorFORMInformation](../FeynGravLibrariesGeneratorFORMInformation.md) or [CalcFormCheck](../../Calculation/CalcFormCheck.md) for an explicit check. Assigning this setting does not enable an automatic startup probe.
