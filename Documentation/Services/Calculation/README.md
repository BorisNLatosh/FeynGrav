# Calculation and FORM

[Documentation index](../../README.md) · [Complete symbol index](../../Symbols.md)

Use [`FeynGravSimplify`](./FeynGravSimplify.md) for the unified calculation interface or the separate export, execution and import commands. A declared loop momentum changes the full pipeline from integrand algebra to supported one-loop coefficient reduction. [`LoopTensorCoefficient`](./LoopTensorCoefficient.md) is an inert result object, not a command that calculates an integral. See the [complete converter guide](./Guide.md) for vocabulary and normalisation.
