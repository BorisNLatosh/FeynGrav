# DisplayInitializationMessages

[Group overview](./README.md) · [Documentation index](../../README.md)

**Symbol:** ``FeynGrav`DisplayInitializationMessages``. **Baseline:** 4.2.0.

`DisplayInitializationMessages[]` reprints the FeynGrav introduction and returns `Null`. It accepts no documented arguments or options. It does not repeat library imports or check FORM availability.

```mathematica
<< FeynGrav`
DisplayInitializationMessages[]
```

The banner identifies the installed package version; it is not a verification of installed optional models or external tools.
