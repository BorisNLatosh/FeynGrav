# FeynGravHowToCite

[Group overview](./README.md) · [Documentation index](../../README.md)

**Symbol:** ``FeynGrav`FeynGravHowToCite``. **Baseline:** 4.2.0.

## Syntax

```mathematica
FeynGravHowToCite[]
```

FeynGravHowToCite[] prints the FeynGrav publications to cite for the version and features used, with reference links, then returns Null. Notebook output contains clickable links; kernels without a front end print plain text and URLs. The command does not access the network, change settings or run calculations. Cite FeynCalc, FORM and FeynArts separately when used. Invalid arguments return Failure.

This reads package citation guidance; it does not query a publication database or certify that a future version has been released.
