# FeynGravCommands

[Group overview](./README.md) · [Documentation index](../../README.md)

**Symbol:** ``FeynGrav`FeynGravCommands``. **Baseline:** 4.2.0 development.

`FeynGravCommands[]` prints the main command list and returns `Null`. It is a discovery aid, not an exhaustive namespace inventory. Load FeynGrav first.

```mathematica
<< FeynGrav`
FeynGravCommands[]
?GravitonScalarVertex
Options[FeynGravSimplify]
```

The usage query shows installed help; `Options` inspects the current option store. The Markdown pages do not install native F1 help. Optional rule generators and benchmarking support have their own loading workflows and contexts.
