# Rule construction

[Documentation index](../../README.md) · [Complete symbol index](../../Symbols.md)

These are auxiliary rule-generation interfaces. Load the specific rule file in a separate fresh kernel. They can have different signatures from the main-package commands of the same name. The [contracts](./Contracts.md) give structural validation; [the generator guide](../LibraryGeneration/Guide.md) explains how rules become installed libraries. Rule availability and successful structural validation do not establish the physics at every order.
