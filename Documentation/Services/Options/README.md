# Options

[Documentation index](../../README.md) · [Complete symbol index](../../Symbols.md)

Each page identifies the option symbol, accepted values and owning commands with their initial defaults. Some symbols belong to Wolfram or FeynCalc; these pages describe only their use in FeynGrav. Option defaults are independent for each facade command. Generator and optional companion policies are stated separately.
