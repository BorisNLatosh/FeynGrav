# Constants and parameters

[Documentation index](../README.md) · [Complete symbol index](../Symbols.md)

These symbols describe couplings, masses, gauge choices and shared conventions. Most physical parameters remain symbolic; they are not immutable numerical constants. Gauge symbols have the initial values stated on their pages. Options belong to the [service option group](../Services/Options/README.md), and `FeynGravInitialized` is an [inspect-only state flag](../Services/PackageInformation/FeynGravInitialized.md).
