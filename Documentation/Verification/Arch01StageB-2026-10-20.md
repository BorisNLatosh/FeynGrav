### Evidence correction — mapping-table check

The as-run candidate block contained this check:

```wl
dataDef = CalcFormConverter`Private`$expressionSpecs;
require["candidate mapping table", Length[OwnValues[dataDef]] > 0, dataDef];
```

That does **not** independently validate the mapping table. Assignment gives
the local symbol `dataDef` its own value; `OwnValues[dataDef]` is therefore
non-empty because of that assignment, independently of the own values of the
converter-private `$expressionSpecs` symbol. This check is not counted as
table validation. The as-run candidate script is preserved unchanged at
`candidate-input/stageB-candidate.wls`, SHA256 `2af08281...`; no kernel was
rerun and no production file changed for this correction.

A corrected future assertion should inspect the fully-qualified table symbol
directly and check its expected shape/content. The following is a proposal,
**unexecuted and not evidence**:

```wl
tableRules = OwnValues[CalcFormConverter`Private`$expressionSpecs];
table = If[Length[tableRules] === 1 &&
    MatchQ[tableRules[[1]], _Rule | _RuleDelayed],
  Last[tableRules[[1]]], Missing["NoUniqueOwnValue"]];
expectedKeys = {"A0", "B0", "C0", "D0", "FeynAmpDenominator",
  "LorentzIndex", "Momentum", "Pair", "Plus", "Power",
  "PropagatorDenominator", "Times"};
require["mapping table shape",
  AssociationQ[table] && Sort[Keys[table]] === expectedKeys &&
  AllTrue[expectedKeys,
    AssociationQ[table[#]] && KeyExistsQ[table[#], "Head"] &&
    MatchQ[table[#]["Arity"], {_Integer | Infinity, _Integer | Infinity}] &] &&
  AllTrue[{"A0", "B0", "C0", "D0"},
    table[#]["FORMName"] === "cf" <> # &&
    table[#]["Arguments"] === "Scalar" &],
  table];
```

This checks one own-value rule, an association with the twelve expected keys,
a `Head`/`Arity` entry for every key, and the four master `FORMName`/
`Arguments` fields. It would still need a fresh bounded kernel under the same
policy before being counted. It is recorded here only as an unexecuted
correction.
